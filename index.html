+ 常见错误诊断指南 (TROUBLESHOOTING HELP)
1. CORS 跨域代理报错 (403 Forbidden / Failed to fetch)
• 说明：请求被浏览器跨域策略拦截。通常发生在直连 NovelAI 时。
• 对策：请在“设置”面板中确保填写了可用的 CORS 跨域代理地址，或为浏览器安装并启用 CORS 解除插件。
2. NovelAI 401 Unauthorized / 身份验证失败
• 说明：NovelAI Key 无效或未配置。
• 对策：检查“设置”面板中的 NovelAI API Key 是否填写正确。它应该是以 pst- 开头的令牌字符串。
3. Stable Diffusion Connection Refused / 500 报错
• 说明：无法连接到本地或远程 SD WebUI 接口。
• 对策：检查“设置”中的 SD 地址是否拼错（默认 http://127.0.0.1:7860），并确保 SD WebUI 启动参数中包含了 --api 和 --cors-allow-origins=*。
4. 422 Unprocessable Entity / 400 Bad Request
• 说明：请求参数无效或超出服务限制。
• 对策：某些 API 对图片生成尺寸、步数有严格阈值，请尝试调小分辨率、步数，或检查选择的模型是否有效。
